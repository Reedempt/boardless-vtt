# 多系統虛擬桌面 (VTT)

一款輕量級、功能強大且跨平台的虛擬桌面 (VTT)，專為角色扮演遊戲 (RPG) 設計，涵蓋從 D&D 和 Pathfinder 等主流系統到小眾獨立遊戲。該軟體注重高效能、完全資料所有權和極高的硬體相容性。

---

## 🚀 專案概述與願景

這款 VTT 的目標是彌合高階桌面環境和入門級行動裝置之間的差距。該軟體經過精心設計，可在各種硬體上流暢運行：

* **目標行動裝置範圍**：針對低階 Android 裝置（售價低於 200 歐元的智慧型手機和平板電腦）以及高階 Apple iOS/iPadOS 裝置進行了最佳化，確保完美運作。
* **桌面生態系統**：全面原生支援 Windows、macOS 和 Linux（任何發行版）。

### 🛠️ 技術堆疊

* **語言與框架**：Kotlin Multiplatform (KMP) + Compose Multiplatform，實作行動端和桌面端 100% 共享的 UI 和業務邏輯。
* **本機儲存**：SQLDelight，提供快速、類型安全性、跨平台的嵌入式資料庫管理。
* **開發環境**：JetBrains 套件（IntelliJ IDEA + DataGrip）。

## 🏗️ 遊戲介面與角色

#### 🔐 身份驗證

* 本機戰役會話通用登入介面。

#### 👑 地下城主 (DM) 介面

* **通用手冊**：整合的超高速文件瀏覽器，可根據當前遊戲系統自適應載入手冊。
* **手冊管理**：支援本機手冊存儲，可直接從內部儲存、外部 USB 隨身碟或 MicroSD 卡讀取資料。
* **戰役控制面板**：戰役概覽、數位骰子產生器、NPC 角色卡以及自訂物品建立器，可將內容注入資料庫，而無需修改主規則資料庫。
* **審批中心**：即時通知中心，用於批准或拒絕玩家提出的角色卡修改請求。

#### ⚔️ 玩家介面

* **互動式角色卡**：完全互動式、可編輯的角色卡，內建骰子產生器。
* **定向規則存取**：直接存取遊戲手冊，僅包含面向玩家的機制（能力、法術、專長、狀態、種族和職業）。
* **同步與提醒引擎**：對角色卡所做的任何結構性變更都會自動觸發向DM的提醒，需經批准後方可生效。
