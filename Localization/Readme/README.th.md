# VTT (Virtual Tabletop) หลายระบบ

Virtual Tabletop (VTT) ที่มีน้ำหนักเบา ทรงพลัง และใช้งานได้หลายแพลตฟอร์ม ออกแบบมาสำหรับเกมสวมบทบาท (RPG) ตั้งแต่ระบบหลักอย่าง D&D และ Pathfinder ไปจนถึงผลิตภัณฑ์อินดี้เฉพาะกลุ่ม สร้างขึ้นโดยเน้นประสิทธิภาพสูง การเป็นเจ้าของข้อมูลอย่างสมบูรณ์ และการเข้าถึงฮาร์ดแวร์อย่างกว้างขวาง

---

## 🚀 ภาพรวมโครงการและวิสัยทัศน์

เป้าหมายของ VTT นี้คือการเชื่อมช่องว่างระหว่างสภาพแวดล้อมเดสก์ท็อประดับสูงและอุปกรณ์พกพาราคาประหยัด ซอฟต์แวร์ได้รับการออกแบบมาให้ทำงานได้อย่างราบรื่นบนฮาร์ดแวร์ทุกระดับ:

* **กลุ่มเป้าหมายมือถือ**: ปรับให้เหมาะสมเพื่อทำงานได้อย่างไร้ที่ติบนอุปกรณ์ Android ระดับล่าง (สมาร์ทโฟนและแท็บเล็ตราคาต่ำกว่า 200 ยูโร) รวมถึงฮาร์ดแวร์ Apple iOS/iPadOS ระดับพรีเมียม
* **ระบบนิเวศเดสก์ท็อป**: รองรับ Windows, macOS และ Linux (ทุกเวอร์ชัน) อย่างเต็มรูปแบบ

### 🛠️ เทคโนโลยีที่ใช้

* **ภาษาและเฟรมเวิร์ก**: Kotlin Multiplatform (KMP) + Compose Multiplatform สำหรับการใช้งาน UI และตรรกะทางธุรกิจร่วมกัน 100% ทั้งบนมือถือและเดสก์ท็อป
* **พื้นที่จัดเก็บข้อมูลภายในเครื่อง**: SQLDelight สำหรับการจัดการฐานข้อมูลแบบฝังตัวที่รวดเร็ว ปลอดภัย และใช้งานได้หลายแพลตฟอร์ม
* **สภาพแวดล้อมการพัฒนา**: JetBrains Suite (IntelliJ IDEA + DataGrip)

## 🔒 นโยบายความเป็นส่วนตัว ความปลอดภัยของข้อมูล และการสร้างรายได้

ซอฟต์แวร์นี้สร้างขึ้นโดยยึดหลักการสำคัญของความเป็นส่วนตัวของผู้ใช้ การเป็นเจ้าของข้อมูลอย่างสมบูรณ์ และความโปร่งใสอย่างแท้จริง:

* **สถาปัตยกรรมแบบออฟไลน์และภายในเครื่อง 100%**: ระบบทำงานแบบออฟไลน์โดยสมบูรณ์ ข้อมูล คู่มือ แคมเปญ และเอกสารตัวละครทั้งหมดจะถูกบันทึกไว้ในฐานข้อมูลภายในเครื่องที่ปลอดภัยบนอุปกรณ์ของคุณเท่านั้น
* **ไม่มีการซิงค์ข้อมูลบนคลาวด์และไม่มีการติดตามจากบุคคลที่สาม**: ซอฟต์แวร์จะไม่ทำการอัปโหลดข้อมูลส่วนบุคคลของคุณไปยังเซิร์ฟเวอร์ภายนอกใดๆ และจะไม่แจกจ่ายหรือขายข้อมูลของคุณให้กับบุคคลที่สาม
* **ประกาศเกี่ยวกับการตรวจสอบสิทธิ์**: ข้อมูลส่วนบุคคลจะถูกใช้เพื่อสร้างบัญชีล็อกอินโปรไฟล์ในเครื่องของคุณ (อีเมลและรหัสผ่าน) เท่านั้น เนื่องจากไม่มีฐานข้อมูลบนคลาวด์ส่วนกลาง **การลืมรหัสผ่านหรืออีเมลที่ลงทะเบียนไว้หมายถึงการไม่สามารถเข้าถึงบัญชีและข้อมูลในเครื่องของคุณได้อย่างถาวร** ไม่มีฟังก์ชัน "รีเซ็ตรหัสผ่าน" บนเซิร์ฟเวอร์
* **ไม่มีโฆษณา, ข้อมูลการใช้งาน หรือโปรแกรมที่ไม่จำเป็น**: ซอร์สโค้ดเป็นสาธารณะและทุกคนสามารถดูได้บน GitHub เพื่อรับประกันว่าไม่มีแอดแวร์, โปรแกรมที่ไม่จำเป็น, สคริปต์ติดตาม, ข้อมูลการใช้งานที่ซ่อนอยู่ หรือโฆษณาที่ทำให้เข้าใจผิด
* **ไม่มีการซื้อขายภายในแอป**: ซอฟต์แวร์นี้ไม่มีการซื้อขายภายในแอป การซื้อในแอป กำแพงการจ่ายเงิน หรือกลไกเกมที่ต้องจ่ายเงินเพื่อปลดล็อกใดๆ ทั้งสิ้น

## 🏗️ หน้าจอเกมและบทบาท

#### 🔐 การตรวจสอบสิทธิ์

* หน้าจอเข้าสู่ระบบแบบรวมสำหรับการเล่นแคมเปญในเครื่อง

#### 👑 หน้าจอ Dungeon Master (DM)

* **คู่มือแบบรวม**: โปรแกรมเรียกดูเอกสารแบบบูรณาการที่ทำงานได้อย่างรวดเร็วเป็นพิเศษ โดยจะโหลดคู่มือตามระบบเกมที่ใช้งานอยู่
* **การจัดการคู่มือ**: รองรับการจัดเก็บคู่มือในเครื่อง โดยอ่านข้อมูลโดยตรงจากหน่วยความจำภายใน ไดรฟ์ USB ภายนอก หรือการ์ด MicroSD
* **แดชบอร์ดแคมเปญ**: ภาพรวมแคมเปญ เครื่องทอยลูกเต๋าดิจิทัล แผ่นข้อมูล NPC และตัวสร้างไอเท็มแบบกำหนดเองที่แทรกเนื้อหาลงในฐานข้อมูลโดยไม่ต้องเปลี่ยนแปลงฐานข้อมูลกฎหลัก
* **ศูนย์อนุมัติ**: ศูนย์กลางการแจ้งเตือนแบบเรียลไทม์เพื่ออนุมัติหรือปฏิเสธการแก้ไขแผ่นข้อมูลตัวละครที่ผู้เล่นร้องขอ

#### ⚔️ หน้าจอผู้เล่น

* **แผ่นข้อมูลตัวละครแบบโต้ตอบ**: แผ่นข้อมูลตัวละครแบบโต้ตอบและแก้ไขได้เต็มรูปแบบ พร้อมเครื่องทอยลูกเต๋าในตัว
* **การเข้าถึงกฎแบบเจาะจง**: เข้าถึงคู่มือเกมโดยตรงที่กรองเฉพาะกลไกที่ผู้เล่นใช้งาน (ความสามารถ เวทมนตร์ ความสามารถพิเศษ สภาวะผิดปกติ เผ่าพันธุ์ และคลาส)
* **ระบบซิงค์และแจ้งเตือน**: การเปลี่ยนแปลงโครงสร้างใดๆ ที่เกิดขึ้นกับแผ่นข้อมูลตัวละครจะแจ้งเตือนไปยัง DM โดยอัตโนมัติ รอการอนุมัติก่อนที่จะมีผลถาวร
