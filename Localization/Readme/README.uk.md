# Багатосистемний віртуальний стіл (VTT)

Легкий, потужний та багатоплатформний віртуальний стіл (VTT), розроблений для рольових ігор (RPG) від масових систем, таких як D&D та Pathfinder, до нішевих інді-продуктів. Створений з акцентом на високу продуктивність, повне володіння даними та надзвичайну доступність обладнання.

---

## 🚀 Огляд та бачення проекту

Метою цього VTT є подолання розриву між високоякісними середовищами робочого столу та бюджетними мобільними пристроями. Програмне забезпечення розроблено для безперебійної роботи на всьому спектрі обладнання:

* **Цільовий діапазон мобільних пристроїв**: Оптимізовано для бездоганної роботи на низькоякісних пристроях Android (смартфони та планшети до 200 євро), а також на преміальному обладнанні Apple iOS/iPadOS.
* **Екосистеми робочого столу**: Повна нативна підтримка Windows, macOS та Linux (будь-який дистрибутив).

### 🛠️ Технологічний стек

* **Мова та фреймворк**: Kotlin Multiplatform (KMP) + Compose Multiplatform для 100% спільного інтерфейсу користувача та бізнес-логіки на мобільних пристроях та настільних комп'ютерах.
* **Локальне сховище**: SQLDelight для швидкого, типобезпечного, багатоплатформного вбудованого керування базами даних.
* **Середовище розробки**: JetBrains Suite (IntelliJ IDEA + DataGrip).

## 🔒 Політика конфіденційності, безпеки даних та монетизації

Це програмне забезпечення побудовано на основних принципах конфіденційності користувачів, повного володіння даними та абсолютної прозорості:

* **100% офлайн та локальна архітектура**: Система працює повністю офлайн. Усі дані, збірники, кампанії та аркуші персонажів зберігаються виключно в захищеній локальній базі даних на вашому фізичному пристрої.
* **Нульова хмарна синхронізація та відсутність відстеження третіми сторонами**: Програмне забезпечення не завантажує ваші особисті дані на жодний зовнішній сервер, а також не розповсюджує та не продає вашу інформацію третім сторонам.
* **Повідомлення про автентифікацію**: Персональні дані використовуються виключно для створення вашого локального профілю (електронна пошта та пароль). Оскільки централізованої хмарної бази даних немає, **втрата пароля або зареєстрованої електронної пошти означає втрату доступу до вашого локального облікового запису та даних назавжди**. Функція сервера «скидання пароля» відсутня.
* **Без реклами, телеметрії чи вірусів**: Вихідний код є публічним і доступний для перегляду будь-кому на GitHub, що гарантує повну відсутність рекламного ПЗ, вірусів, скриптів відстеження, прихованої телеметрії чи оманливої ​​реклами.
* **Без мікротранзакцій**: Програмне забезпечення не містить мікротранзакцій, покупок у додатку, платних доступів або платних ігрових механік будь-якого виду, які можна розблокувати.

## 🏗️ Ігрові екрани та ролі

#### 🔐 Автентифікація

* Універсальний екран входу для локальних сесій кампанії.

#### 👑 Екран Dungeon Master (DM)

* **Універсальний компендіум**: Інтегрований, надшвидкий браузер документації, який адаптивно завантажує посібники залежно від активної ігрової системи.
* **Керування посібниками**: Підтримка локального зберігання посібників, зчитування даних безпосередньо з внутрішньої пам'яті, зовнішніх USB-накопичувачів або карт MicroSD.
* **Інформаційна панель кампанії**: Огляд кампанії, цифровий кидок кубиків, аркуші NPC та засоби створення власних предметів, які вставляють контент у базу даних без зміни основної бази правил.
* **Центр затвердження**: Центр сповіщень у режимі реального часу для затвердження або відхилення змін аркуша персонажа, запитуваних гравцями.

#### ⚔️ Екран гравця

* **Інтерактивний аркуш персонажа**: Повністю інтерактивні, редаговані аркуші персонажів із вбудованим кидком кубиків.
* **Доступ до цільових правил**: Прямий доступ до ігрових посібників, відфільтрованих виключно за механіками, орієнтованими на гравця (здібності, заклинання, подвиги, умови статусу, раси та класи).
* **Механізм синхронізації та сповіщень**: Будь-яка структурна зміна, внесена до аркуша персонажа, автоматично запускає сповіщення для Ведучого, яке очікує схвалення, перш ніж стати постійним.
