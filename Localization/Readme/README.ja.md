# マルチシステム対応VTT（バーチャルテーブルトップ）

D&DやPathfinderといった主流システムからニッチなインディーズ作品まで、幅広いロールプレイングゲーム（RPG）に対応する、軽量かつパワフルなマルチプラットフォーム対応バーチャルテーブルトップ（VTT）です。高性能、完全なデータ所有権、そして極めて高いハードウェア互換性を重視して開発されています。

---

## 🚀 プロジェクト概要とビジョン

このVTTの目標は、ハイエンドデスクトップ環境と低価格モバイルデバイスの間のギャップを埋めることです。ソフトウェアは、あらゆるハードウェア環境でスムーズに動作するように設計されています。

* **対象モバイル端末**: 低価格帯のAndroid端末（200ユーロ以下のスマートフォンやタブレット）から、ハイエンドのApple iOS/iPadOS端末まで、あらゆるデバイスで完璧に動作するように最適化されています。
* **デスクトップ環境**: Windows、macOS、Linux（あらゆるディストリビューション）を完全にネイティブサポートしています。


### 🛠️ 技術スタック

* **言語とフレームワーク**: Kotlin Multiplatform (KMP) + Compose Multiplatform により、モバイルとデスクトップ間でUIとビジネスロジックを100%共有できます。
* **ローカルストレージ**: SQLDelight により、高速で型安全なマルチプラットフォーム組み込みデータベース管理を実現します。
* **開発環境**: JetBrains Suite (IntelliJ IDEA + DataGrip)。

---

## 🔒 プライバシー、データセキュリティ、収益化ポリシー

このソフトウェアは、ユーザーのプライバシー、データの完全な所有権、そして絶対的な透明性という基本原則に基づいて構築されています。

* **100%オフライン＆ローカルアーキテクチャ**: システムは完全にオフラインで動作します。すべてのデータ、コンペンディウム、キャンペーン、キャラクターシートは、物理デバイス上の安全なローカルデータベースにのみ保存されます。
* **クラウド同期なし＆第三者による追跡なし**: 本ソフトウェアは、お客様の個人データを外部サーバーにアップロードしたり、第三者に配布または販売したりすることはありません。
* **認証に関する注意事項**: 個人データは、お客様のローカルプロファイルログイン（メールアドレスとパスワード）の生成のみに使用されます。中央集権型のクラウドデータベースが存在しないため、**パスワードまたは登録済みメールアドレスを紛失すると、ローカルアカウントとデータへのアクセス権が永久に失われます**。「パスワードリセット」サーバー機能はありません。
* **広告、テレメトリ、ブロートウェアなし**: ソースコードはGitHubで公開されており、誰でも閲覧可能です。これにより、アドウェア、ブロートウェア、トラッキングスクリプト、隠されたテレメトリ、誤解を招く広告が一切存在しないことが保証されます。
* **マイクロトランザクションなし**: 本ソフトウェアには、マイクロトランザクション、アプリ内課金、ペイウォール、有料のアンロック可能なゲームメカニズムは一切ありません。

## 🏗️ ゲーム画面と役割

#### 🔐 認証

* ローカルキャンペーンセッション用の共通ログイン画面。

#### 👑 ダンジョンマスター（DM）画面

* **ユニバーサルコンペンディウム**: アクティブなゲームシステムに応じてマニュアルを自動的に読み込む、統合された超高速ドキュメントブラウザ。
* **マニュアル管理**: ローカルマニュアルの保存に対応し、内蔵ストレージ、外部USBドライブ、またはmicroSDカードから直接データを読み込むことができます。
* **キャンペーンダッシュボード**: キャンペーン概要、デジタルダイスローラー、NPCシート、およびマスタールールデータベースを変更せずにコンテンツをデータベースに挿入するカスタムアイテム作成機能。
* **承認センター**: プレイヤーが要求したキャラクターシートの変更を承認または拒否するためのリアルタイム通知ハブ。

#### ⚔️ プレイヤー画面

* **インタラクティブキャラクターシート**: ダイスローラー内蔵の、完全にインタラクティブで編集可能なキャラクターシート。
* **対象を絞ったルールアクセス**: プレイヤー向けのゲームメカニクス（能力、呪文、特技、状態異常、種族、クラス）に絞り込んだゲームマニュアルに直接アクセスできます。
* **同期＆アラートエンジン**: キャラクターシートに構造的な変更が加えられると、自動的にゲームマスター（DM）にアラートが送信され、承認されるまで変更は確定されません。
