# 多系统虚拟桌面 (VTT)

一款轻量级、功能强大且跨平台的虚拟桌面 (VTT)，专为角色扮演游戏 (RPG) 设计，涵盖从 D&D 和 Pathfinder 等主流系统到小众独立游戏。该软件注重高性能、完全数据所有权和极高的硬件兼容性。

---

## 🚀 项目概述与愿景

这款 VTT 的目标是弥合高端桌面环境和入门级移动设备之间的差距。该软件经过精心设计，可在各种硬件上流畅运行：

* **目标移动设备范围**：针对低端 Android 设备（售价低于 200 欧元的智能手机和平板电脑）以及高端 Apple iOS/iPadOS 设备进行了优化，确保完美运行。
* **桌面生态系统**：全面原生支持 Windows、macOS 和 Linux（任何发行版）。

### 🛠️ 技术栈

* **语言与框架**：Kotlin Multiplatform (KMP) + Compose Multiplatform，实现移动端和桌面端 100% 共享的 UI 和业务逻辑。
* **本地存储**：SQLDelight，提供快速、类型安全、跨平台的嵌入式数据库管理。
* **开发环境**：JetBrains 套件（IntelliJ IDEA + DataGrip）。

## 🔒 隐私、数据安全与盈利政策

本软件秉承用户隐私、完全数据所有权和绝对透明的核心原则：

* **100% 离线本地架构**：系统完全离线运行。所有数据、资料库、战役和角色卡均保存在您物理设备上的安全本地数据库中。
* **零云同步，无第三方追踪**：本软件不会将您的个人数据上传到任何外部服务器，也不会将您的信息分发或出售给第三方。 
* **身份验证通知**：个人数据仅用于生成您的本地个人资料登录信息（电子邮件和密码）。由于没有集中式云数据库，**如果您丢失密码或注册邮箱，将永久失去对本地帐户和数据的访问权限**。我们没有“重置密码”服务器功能。
* **无广告、遥测或臃肿软件**：源代码在 GitHub 上公开，任何人都可以查看，以保证完全没有广告软件、臃肿软件、跟踪脚本、隐藏的遥测或误导性广告。
* **无微交易**：该软件不包含任何形式的微交易、应用内购买、付费墙或付费解锁的游戏机制。

## 🏗️ 游戏界面与角色

#### 🔐 身份验证

* 本地战役会话通用登录界面。

#### 👑 地下城主 (DM) 界面

* **通用手册**：集成的超高速文档浏览器，可根据当前游戏系统自适应加载手册。
* **手册管理**：支持本地手册存储，可直接从内部存储、外部 USB 驱动器或 MicroSD 卡读取数据。
* **战役控制面板**：战役概览、数字骰子生成器、NPC 角色卡以及自定义物品创建器，可将内容注入数据库，而无需修改主规则数据库。
* **审批中心**：实时通知中心，用于批准或拒绝玩家提出的角色卡修改请求。

#### ⚔️ 玩家界面

* **交互式角色卡**：完全交互式、可编辑的角色卡，内置骰子生成器。
* **定向规则访问**：直接访问游戏手册，仅包含面向玩家的机制（能力、法术、专长、状态、种族和职业）。
* **同步与提醒引擎**：对角色卡所做的任何结构性更改都会自动触发向DM的提醒，需经批准后方可生效。
